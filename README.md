# Abbel — Developer Portfolio

Interactive 3D Blocky Portfolio focused on **Web Development** and **Junior Cyber Security**.

- **Live Portfolio:** [nottbell.vercel.app](https://nottbell.vercel.app)
- **GitHub:** [github.com/notbell1](https://github.com/notbell1)

---

## Tech Stack

- **Core:** JavaScript (ES Modules), HTML5, CSS3
- **Styling:** Tailwind CSS v4
- **3D Engine:** Three.js (Interactive 3D Block Matrix & Floating Tech Cubes)
- **Build Tool:** Vite
